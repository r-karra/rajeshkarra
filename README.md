# rajeshkarra 🚀

> High-contrast, space-grade developer & AI research portfolio built with Next.js (App Router), Tailwind CSS, and Lucide Icons.

Showcasing technical research in the **JAX Ecosystem**, **Large Language Models (Gemma / Transformers)**, **Quantum AI (Cirq / Qiskit / TFQ)**, and **Mathematical Proof Foundations**.

## 🌟 Features

- **Star Light / Space Aesthetic**: Deep obsidian void theme (`#030712`), ambient cyan/violet radial glows, and glassmorphic cards.
- **Zero-Reload Tab Navigation**: Instant client-side switching across:
  - **Overview**: Biography, strategic research agenda, and full technical skills matrix.
  - **Developments & Repos**: Project showcase and interactive Colab / Kaggle monospace links (`[open with colab]`, `[kaggle kernel link]`).
  - **Technical Notes**: Markdown-ready documentation and high-contrast code snippet cards with instant clipboard copy.
  - **Readings & Papers**: Curated bibliography of textbooks and landmark DeepMind / Google Research papers.
  - **Media Matrix**: 2-column video lecture grid with timestamps and topic filters.
- **Semantic & Accessible**: Full semantic HTML tags (`<header>`, `<main>`, `<article>`, `<nav>`, `<footer>`) with genuine external links.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open http://localhost:3000
```

## 📦 Deployment to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```
Or import directly via the [Vercel Dashboard](https://vercel.com/new).
